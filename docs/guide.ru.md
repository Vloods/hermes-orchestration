# Роли, безопасность и диагностика

![Схема маршрутизации](../assets/architecture.svg)

**Два механизма:** `delegate_task` — синхронный вызов дочернего агента с возвратом результата родителю; Kanban — постоянная очередь карточек, которые получает отдельный процесс назначенного профиля. Краткая задача не требует доски. Долговременная работа, повторные попытки, обзор и участие человека — причины выбрать Kanban. Исходный запрос остаётся ответственностью супервизора даже при делегировании.

**Изоляция:** `solver` имеет отдельные настройки, память и навыки; учётные данные профиля имеют приоритет, но Hermes может читать авторизацию из корня **того же** Hermes home, если у профиля нет собственной записи для провайдера. Это не граница безопасности учётных данных. Общая доска внутри одного Hermes home не означает общий контекст диалога. Проектный `.hermes.md` применяется в проектном рабочем каталоге, но не гарантированно в изолированном scratch/worktree карточки; передавайте критические критерии и запреты в тело задачи и проверяйте workspace. `kanban.orchestrator_profile` не подставляет промпт профиля в автоматический декомпозер: модель этого шага задаёт `auxiliary.kanban_decomposer`.

**Безопасные исходные параметры:** автоматическое разрешение опасных команд у дочернего агента выключено, как и автоматическая декомпозиция triage. Исходная локальная конфигурация разрешала команды дочерним агентам; для соответствия ей нужен отдельный осознанный выбор `delegation.subagent_auto_approve: true` после оценки риска. Скрипт установки по умолчанию ничего не пишет, существующие файлы не перезаписывает, резервные копии создаёт только при явном `--backup-existing --apply`. Старый YAML не объединяется с новым. Авторизация только официальным `hermes setup`, без копирования `.env` или токенов.

Если карточка остаётся `ready`, проверьте `HERMES_HOME="$SANDBOX" hermes gateway status`, `HERMES_HOME="$SANDBOX" hermes kanban dispatch --dry-run` и существование назначенного профиля. Отладка результата: `HERMES_HOME="$SANDBOX" hermes kanban show TASK_ID`, `HERMES_HOME="$SANDBOX" hermes kanban runs TASK_ID`. Без запущенного gateway диспетчер не обработает очередь. Тесты репозитория не создают карточки и не вызывают платную модель.

Источники: [официальный справочник Kanban](https://hermes-agent.nousresearch.com/docs/user-guide/features/kanban), [профили](https://hermes-agent.nousresearch.com/docs/user-guide/profiles), [установка](https://hermes-agent.nousresearch.com/docs/getting-started/installation). Синтаксис актуальной установленной версии проверяйте через `hermes --help`.
